# Importing an external component into ViART

External blocks (21st.dev, shadcn/ui, Tailwind UI snippets) always arrive in a generic
style: rounded-2xl cards, indigo accents, drop shadows, `lucide-react` icons, English
copy. They are a **structure reference**, not a drop-in.

Read `.claude/skills/frontend-design/SKILL.md` first — it holds the tokens this
adaptation targets.

## Procedure

1. **Keep the structure, drop the skin.** Preserve the component's DOM/semantics and
   interaction logic. Delete its colours, radii, shadows and font sizes.
2. **Re-class it.** The project styles with semantic class names in
   `app/globals.css` (`.service-line`, `.complex-line`, `.rating-anchor`, …), not with
   long Tailwind chains. Give the imported block one section class plus element classes
   in the same naming style, and add its CSS as a new block at the end of the
   relevant area of `globals.css`.
3. **Swap the tokens.** Background → `--cocoa`/`--espresso`; text → `--ivory`;
   secondary text → `--muted`; accent → `--bronze`/`--bronze-soft`; every border →
   `1px solid var(--hairline)`. Remove `box-shadow` — this design separates surfaces
   with hairlines and value, not shadows.
4. **Fit the rhythm.** Wrap in `<section className="chapter …">`, add the next
   `.chapter-index.tech-label` number (`NN / NAME`), keep the page inset
   (`var(--page-gutter)`), and use the 8px spacing steps.
5. **Replace the content.** Russian copy, real ViART services/prices, real photos from
   `public/images/`. Never ship lorem ipsum, placeholder avatars or invented
   testimonials — reviews come from the `reviews` array in `app/page.tsx`.
6. **Add motion last.** Wrap with `Reveal` / `RevealGroup` + `RevealChild` from
   `app/components/motion.tsx`, using the `as` prop so no extra `<div>` is introduced.
7. **Check dependencies.** Prefer zero new packages. If the block needs
   `lucide-react`, `clsx`, `class-variance-authority` or a Radix primitive, first ask
   whether the same result can be reached with the existing arrow glyphs and plain CSS.
   `next/image` is mandatory for images.
8. **Verify statically** at 1440px, 1100px, 899px and 640px: check the element, its
   parent grid, selector order, and the responsive overrides in `globals.css`.
   Then hand it to the user for visual confirmation — do not start a dev server.

## Rejection list

If the pasted component brings any of these, strip them before integrating:
rounded-2xl/3xl cards · gradient text · glassmorphism · emoji icons · avatar rows ·
`shadow-lg`/`shadow-2xl` · animated gradient borders · marquee logo strips ·
"Trusted by 10,000+ customers" style social proof · dark/light theme toggles
(the site is warm-dark only).

## Using the Magic MCP server (21st.dev)

`.mcp.json` registers the `magic` server. It needs `TWENTY_FIRST_API_KEY` in the
environment (key from https://21st.dev/magic/console); without it the server simply
won't start and components can be pasted in by hand instead.

Prompt shape that works well here:

> Generate a <section> for … . Dark warm-brown palette, ivory text, 1px hairline
> borders, no shadows, no rounded corners, asymmetric two-column grid, monospace
> uppercase metadata labels. Plain CSS classes, no Tailwind utilities.

Then run the 8-step procedure above on the result.
